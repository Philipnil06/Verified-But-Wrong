# VBW External Vericoding Audit Patch

This folder is a hardened drop-in patch for adding the External Vericoding Benchmark Audit.

Important: do not blindly overwrite an existing repository. Copy the new `external_vericoding_audit/` directory and `external_vericoding_cases/` directory, then merge the external audit block into existing `run_all_repro.py` and merge the external evidence section into existing `analysis/evidence_pack.py`.

See `README_external_vericoding_audit.md` and `reports/external_vericoding_integration_notes.md`.
